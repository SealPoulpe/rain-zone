# Rain Zone

Simple falling blocks simulator created in React. <br>
Individual blocks are created and catalogued, deleted block IDs are re-used. <br>
<br>
For use in potential auto-clicker.

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
