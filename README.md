# Rain Zone

Simple falling blocks simulator created in React.
Individual blocks are created and catalogued, deleted block IDs are re-used.

### `npm start`

Runs the app in dev mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
